# Warriors — Official Fan Site (unofficial!)

A fan website about Erin Hunter's **Warriors** series (the original *Warrior Cats* books), made by **Percy ⚡** for **The Beast**.

## What's inside

| Page | What it covers |
|---|---|
| `index.html` | Series overview, the 9 arcs, the 5 Clans, where to start |
| `books.html` | Every arc, every book, novellas, field guides, manga and graphic novels |
| `clans.html` | Clan territories, names, ranks, medicine cats, religions |
| `characters.html` | The cats, grouped by Clan + ancient cats + outside-the-Clans |
| `code.html` | The Warrior Code — the original 16 laws and the revised 14 |
| `quiz.html` | 15-question lore quiz with demigod-style ranks |
| `clan-quiz.html` | "Which Clan are you?" personality quiz |

## Tech

Static HTML, CSS and vanilla JavaScript. No build step, no frameworks.

```
css/style.css   # forest / moss / amber theme
js/main.js      # scroll reveal + active nav
js/quiz.js      # lore quiz engine
js/clanquiz.js  # Clan quiz engine
```

## Run it locally

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```
